# Fragmented Worlds

## Checkpoint A: genuine fragmentation foundation

The reference solid is a regular tetrahedron of axis-aligned width 10,000 to
1,000,000,000 meters. Four cones connect its boundary triangles to one strictly
interior point. Eight deterministic seed patterns permute barycentric weights
22%, 24%, 26%, 28%. Each resulting unequal tetrahedral fragment has one original
outer face and three real exposed break faces. All four surfaces are editable.
This is a partition of one common body, not an arrangement of unrelated solids.

Local coordinates use each fragment's centroid. Initial positions separate
those centroids radially by 15% to 300%. Rotation and bounded uniform arrangement
scale preserve local geometry and elevation words. Convex separating-axis tests
reject intersecting, touching and numerically uncertain configurations. Surface
geography remains in the immutable local reference metric.

Each fragment uses 2*N*N+2 canonical samples: 32,770 at N128 and 131,074 at
N256. Four N256 pieces total 524,296 samples (2,097,184 authority bytes), beneath
the unchanged aggregate component budget. No display or worker capacity cap
was raised. Physical joins have one canonical word; empty space has no aliases.

The existing Floating Islands document, worker/session, brush, perspective
scene, connected editor, atlas, palette/relief and history contracts are shared
incrementally. Floating Islands retain rigid poses and their exact v31/v32
interpretations. Fragment arrangement scale is isolated to the new family.

Validation: twelve targeted numerical/shared tests cover volume partition,
closed convex boundaries, opposite break normals, all bounded map nets,
canonical ownership, intrinsic distances, four brushes, exact history and
isolation. TypeScript and production build pass. Three installed-Chrome
regressions pass: Floating Islands N128 actual WebGL2/Canvas workflows with
exact v32 reopening, and independent physical-world pixel reference checks.
Evidence is frozen in `evidence/fragmented-foundation/receipt.json`.

This checkpoint is a geometry foundation. Fragmented World creation and strict
persistence are not yet exposed as an operational World. No excavation,
custom cutting, displacement meshing or other World family is implemented.
Owner acceptance remains separate from technical validation.

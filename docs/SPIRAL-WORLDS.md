The physical model is a planar Archimedean generating centerline, `r(theta) = innerRadius + turnSpacing * theta / (2*pi)`, over `0 <= theta <= 2*pi*turns`. Sixty-four straight material strips between actual tangent-normal stations define the reference body. Its cross-section is rectangular, with nonzero vertical thickness and two genuine flat terminal closures. Station widths are exact; the actual affine facets define intermediate width, positions, tangent frames, normals and metrics. Analytic generating-curve length is stored separately from the shorter sum of the actual centerline chords. Clockwise winding reflects the generating plane and exchanges the chart banks to preserve outward orientation. The World is neither longitudinally periodic nor an analytic smooth sweep hidden beneath another mesh.

Supported structural controls are World Size (uniform scale 100,000-1,000,000,000 m), 1.5-3 turns, centerline Inner Radius 10-25% of Size, radial Turn Spacing 12-28%, Body Width 7-16% and Body Thickness 30-90% of width. Width must be below 90% of spacing and the inner normal-offset curvature bound must remain below 0.75. Every constructed nonadjacent outline-edge pair is checked for actual intersection/touching; every material strip must be strictly convex and correctly oriented. These physical checks follow parameter validation. A separate creator capacity check retains a useful three-cell default brush and rejects undersampled combinations before terrain allocation; the Thin preset requires Higher detail. Presets include traditional, open, compact, close separate turns, long and thin bodies. Dimensions are creation-only, preserving sculpted geography rather than remapping it silently.

The closed boundary has 260 vertices, 258 physical quadrilaterals, 516 triangle charts and 774 chart edges, Euler characteristic 2. Both terminal interiors are distinct. Upper/lower and lateral/terminal interiors retain independent numerical words; shared physical boundaries own one canonical word. N128/N256 equivalent uses n32/n64 per chart: 264,194 / 1,056,770 Float32 samples and 1,056,776 / 4,227,080 authority bytes. Initialization is the shared -100 m ocean, with explicit rejection outside the supported +/-thickness/8 elevation interval. Heights color the numerical reference surface, following the existing Atlas architecture.

Same-cap global distance is the certified shortest planar route in the actual winding polygon. Projection of every exterior path is nonexpansive and stays in this extruded material domain, so it supplies the matching global lower bound. Shared prism visibility graphs, interval arithmetic and exact orientation signs retain the real gaps. Developed lateral strips, local cap/wall unfoldings and vertex cones provide certified qualified surface routes below half thickness. Unsupported nonlocal mixed-surface queries fail explicitly. A continuous piecewise affine station scalar on the complete exterior has an outward-rounded maximum gradient; its Lipschitz bound cheaply rejects geographically distant turns before expensive queries. It supplies only a LOWER bound, never influential brush distance. There is no blanket turn-isolation mask. Arbitrary large brushes are not claimed: interactive radii remain below 24% of thickness and within the unchanged candidate, metric-query, prepared-patch, history and queue budgets. Longer same-cap metric queries and full winding pointer paths remain supported.

The editor reuses the accepted welded Float32 authority, connected brush/stroke/history, preview workers, scheduling, session and Atlas workspace. Raise, Lower, Smooth and Flatten cover the inner/middle/outer upper surfaces, corresponding undersides, inward/outward walls and both real terminals. Region focus clears genuinely occluding turns using the actual picker. Rotation, pan, zoom, Fit, tools and brush settings retain the shared interaction model. Upper and underside maps keep recognizable physical outlines. Nine perimeter rows preserve true physical length and thickness without a giant strip; row cuts do not change numerical ownership or intrinsic distances. Persisted view `phase` is an explicit framing selector (0 complete atlas, 1 cap footprint, 2 wall rows), never longitudinal wrapping.

Rendering uses the accepted indexed field, cube palette/physical relief, polygon color atlases, static-triangle depth GPU and prism Canvas composition. Qualified physical atlas spacing advances at most half a native coordinate cell per axis. Actual concave cap outlines and contiguous wall-run masks compose only real material; no hull bridges gaps. A geometry adapter supplies nearest physical polygon-boundary gutter positions. Narrow actual-boundary quarter rays correct subpixel joins, with a one-pixel radius at coplanar chart joins and a three-pixel radius at material creases, under the unchanged 131,072-pixel repair cap. In the normal workspace, geometry/color preparation yields in nominal four-millisecond idle slices, cancels obsolete epochs and resumes after input. Navigation keeps a coherent sharp base image; existing prepared correction caches update during painting. The shared workspace adds an optional interaction hook; other providers retain their prior path.

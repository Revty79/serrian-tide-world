## Solid Tetrahedron numerical checkpoint

Published as `a1b532ea5f5244a62d39b21a6cbff5463d401340` with clean-tree and
GitHub `main` parity verified before operational work began.

The model is a regular tetrahedron controlled by physical edge length, with four
equilateral triangles, four shared vertices and six physical edges. The base is
an actual triangle. The centroid is the physical origin; height is
`edge * sqrt(2/3)` and inradius is one quarter of that height. Explicit oriented
face winding yields outward unit normals and a closed convex boundary.

`polyhedron-contract.ts` extracts only the geometry hooks needed by the accepted
Pyramid unfolding solver: real faces, incidence, physical frames, chart vertices
and outward interval coordinates. The exhaustive solver, prepared affine route
certificates, portal order tests, feasible witnesses and safe precision failures
are reused in `polyhedron-path.ts` and `polyhedron-distance-prepared.ts`.
The old Pyramid imports remain compatibility entry points for those mechanisms;
its geometry supplies the same interval expressions as before extraction.

Every distinct tetrahedron face pair is adjacent. There is no nonadjacent pair
to fabricate. Each pair retains all five simple face routes, including routes
through either or both remaining faces; endpoint, edge and vertex cases exercise
the same certified global boundary search. The analytic adjacent-centroid
distance is `edge / sqrt(3)`, strictly longer than the ambient material chord.

The triangular lattice uses the accepted indexed Float32 authority and exact
vertex/edge/interior ownership. It stores `2*N*N + 2` canonical words: 32,770 at
N128 and 131,074 at N256. Face aliases never own duplicate terrain. Foreign keys
include the complete geometry signature, identity, resolution and representation.
Snapshots are private, finite elevations obey physical bounds, and guarded patch
commits retain the existing atomic source-epoch checks.

`createPolyhedronBrush` reuses the accepted connected dab/stroke/history engines.
It extracts the existing Pyramid conservative planar candidate projection,
certified distance queries, smoothing weights and visible-boundary guard into
one adapter factory. Both shapes use that factory. The radius policy derives
from real edge spacing and physical dimensions; defaults exceed three lattice
spacings at N128/N256. No blur, stronger brush, volume shortcut, replacement
painting engine or larger hard work/history budget is introduced.

Focused verification covers analytic dimensions and distance enclosures,
all canonical aliases, immutable physical/interval coordinates, non-power-of-two
lattices, symmetric neighbors, all four tools, exact whole-gesture Undo/Redo,
conservative candidates, rejected/stale epochs and atomic cancellation. Forty
N128/N256 tetrahedron dabs match the exhaustive solver's actual Float32 words;
the forty existing Pyramid equivalence dabs remain identical as well.

The numerical checkpoint does not claim an operational Tetrahedron editor.
Normal selector, sharp shared presentation, workers, workspace and strict
persistence follow as the next separately verified checkpoint.
